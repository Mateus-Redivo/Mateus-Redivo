## About

I build software and teach how to build it. My work sits between the classroom and the editor: I turn what I learn in practice into structured study material, and use teaching to sharpen how I write code.

- Graduated in Information Systems from UEMG - Passos
- Teaching Object-Oriented Programming, Software Architecture, and Algorithms
- Currently focused on Python, Java, C, and SQL
- Always open to questions, discussions, and tech ideas

## Featured Projects

Open study tracks I maintain and use in my classes. Each one is a sequence of modules with theory, runnable examples, exercises, and an answer key. The content is written in Portuguese.

| Project | Stack | Description |
| --- | --- | --- |
| [TrilhaPython](https://github.com/Mateus-Redivo/TrilhaPython) | Python | Programming logic from zero to a complete system: types, control flow, functions, error handling, sorting algorithms, a CRUD case study, and a final integrative project. |
| [TrilhaPOO](https://github.com/Mateus-Redivo/TrilhaPOO) | Java | Object-Oriented Programming in 18 modules: classes, encapsulation, inheritance, polymorphism, abstraction, interfaces, exceptions, and refactoring, ending with a banking case study. |

More on my [GitHub profile](https://github.com/Mateus-Redivo?tab=repositories).
